# django localization - how to create language files
run these commands from the root directory of the django project (where `manage.py` is)

#### for italian
```
django-admin makemessages -l it -e html
```

#### for korean
```
django-admin makemessages -l ko -e html
```

https://docs.djangoproject.com/en/5.1/topics/i18n/translation/
